01 · Overview

What You'll Learn

Bayesian analysis lets you reason about uncertainty in a principled way, starting from a prior belief, then updating that belief as new evidence arrives. In this tutorial, we apply that idea to a real problem: predicting the probability that a loan will default given what we know about the borrower.

We build a Bayesian Network using three features from a LendingClub-style dataset (interest rate, debt-to-income ratio, and FICO score) and use it to compute the posterior probability of default across all 27 possible combinations of those features.

What you need
A loan dataset with columns: int_rate, dti, fico_range_high, bad_loan. The code runs in Jupyter, Google Colab, or Spyder.
02 · Setup

Imports & Installation

Install pgmpy if you haven't already, then import everything we need.

setup.py 
import warnings
warnings.filterwarnings('ignore')

# Install pgmpy if needed:
# !pip install pgmpy

import pandas as pd
from sklearn.preprocessing import KBinsDiscretizer
from pgmpy.models import DiscreteBayesianNetwork
from pgmpy.estimators import BayesianEstimator
from pgmpy.inference import VariableElimination
Note
Use DiscreteBayesianNetwork (not BayesianNetwork). It's the current recommended class in pgmpy. The older name still works but triggers deprecation warnings.
03 · Data

Load & Prepare the Dataset

We select the four columns we need and drop any rows with missing values. The bad_loan column is our target: 1 means the loan defaulted, 0 means it was repaid.

load_data.py 
# Load your dataset — update the path to match your file
df = pd.read_csv("lendingclub_sample_25000.csv")

# Select relevant columns and drop missing values
df = df[['int_rate', 'dti', 'fico_range_high', 'bad_loan']].dropna()
df['bad_loan'] = pd.to_numeric(df['bad_loan'], errors='coerce')
df = df.dropna()

print(f"Dataset shape: {df.shape}")
print(f"Overall default rate: {df['bad_loan'].mean():.1%}")
04 · Preprocessing

Discretize Features into Bins

Bayesian Networks work with discrete variables. We convert our three continuous features into three bins each (Low, Medium, High) using quantile-based binning so each bin has roughly the same number of observations.

discretize.py 
bin_features = ['int_rate', 'dti', 'fico_range_high']

discretizer = KBinsDiscretizer(
    n_bins=3,
    encode='ordinal',
    strategy='quantile'   # equal-frequency bins
)

df[bin_features] = discretizer.fit_transform(df[bin_features])
df[bin_features] = df[bin_features].astype(int)
df['bad_loan']   = df['bad_loan'].astype(int)

# Encoding: 0 = Low, 1 = Medium, 2 = High
Why quantile binning?
Quantile binning ensures each bin contains roughly equal numbers of observations, important for reliable probability estimates. Equal-width binning can leave some bins nearly empty when data is skewed.
05 · Model

Define the Bayesian Network

We define the graph structure: each of our three features has a directed edge to bad_loan. This encodes our prior belief that interest rate, DTI, and FICO score each independently influence default risk. We then fit the model using a Bayesian Estimator with a BDeu prior (Bayesian Dirichlet equivalent uniform), which handles small sample sizes gracefully.

bayesian_network.py 
model = DiscreteBayesianNetwork()

model.add_nodes_from(['int_rate', 'dti', 'fico_range_high', 'bad_loan'])

model.add_edges_from([
    ('int_rate',      'bad_loan'),
    ('dti',           'bad_loan'),
    ('fico_range_high','bad_loan')
])

# Fit using Bayesian Estimator with BDeu prior
model.fit(df, estimator=BayesianEstimator, prior_type='BDeu')

# Inspect the conditional probability distributions
for cpd in model.get_cpds():
    print("CPD of", cpd.variable)
    print(cpd)

# Set up inference engine
inference = VariableElimination(model)
06 · Inference

Query the Model

Now we can ask the model: "Given a borrower with high interest rate, high DTI, and low FICO score, what is the probability of default?" This is the posterior probability after updating our prior with the evidence.

inference.py 
# Query: high interest rate (2), high DTI (2), low FICO (0)
query = inference.query(
    variables=['bad_loan'],
    evidence={
        'int_rate':       2,   # High
        'dti':            2,   # High
        'fico_range_high':0    # Low
    }
)

print(query)
# Encoding reminder: 0=Low, 1=Medium, 2=High
Expected Output +-------------+------------------+ | bad_loan | phi(bad_loan) | +=============+==================+ | bad_loan(0) | 0.3241 | +-------------+------------------+ | bad_loan(1) | 0.6759 | +-------------+------------------+

The model estimates a ~68% probability of default for this high-risk profile, substantially above the baseline default rate in the dataset.

07 · Grid Search

Loop Through All 27 Combinations

Rather than querying one profile at a time, we iterate through all 3×3×3 = 27 combinations of feature values and compute the default probability for each. This gives us a complete risk grid.

risk_grid.py 
import itertools

rows = []
for i, j, k in itertools.product(range(3), repeat=3):
    q = inference.query(
        variables=['bad_loan'],
        evidence={'int_rate': i, 'dti': j, 'fico_range_high': k}
    )
    prob = q.values[1]   # probability that bad_loan = 1
    rows.append({
        'int_rate':       i,
        'dti':            j,
        'fico_range_high':k,
        'P(bad_loan)':    prob
    })

df_results = pd.DataFrame(rows)

# Map numeric bins back to readable labels
label_map = {0: 'Low', 1: 'Medium', 2: 'High'}
df_results['int_rate']        = df_results['int_rate'].map(label_map)
df_results['dti']             = df_results['dti'].map(label_map)
df_results['fico_range_high'] = df_results['fico_range_high'].map(label_map)

# Round and display
df_results = df_results.round(3)

# Optional: save to CSV
# df_results.to_csv("bayesian_bad_loan_risk.csv", index=False)
08 · Results

Interpret the Risk Grid

Sort the results to surface the highest-risk borrower profiles. The table below shows what the model output looks like. Your exact numbers will vary based on your dataset.

results.py 
print("Overall default rate:", df['bad_loan'].mean().round(3))
print()
print(
    df_results
    .sort_values('P(bad_loan)', ascending=False)
    .to_string(index=False)
)
Sample Output Overall default rate: 0.142 int_rate dti fico_range_high P(bad_loan) High High Low 0.676 High Medium Low 0.598 Medium High Low 0.541 High High Medium 0.487 High Low Low 0.463 ... Low Low High 0.071
Key Insight
The highest-risk profile (High rate · High DTI · Low FICO) has nearly 5× the default probability of the lowest-risk profile. The Bayesian Network quantifies what underwriters already know intuitively, and makes it actionable.

This risk grid can feed directly into a credit scorecard, a loan approval threshold system, or a monitoring dashboard, giving you a probabilistic foundation for every decision.
